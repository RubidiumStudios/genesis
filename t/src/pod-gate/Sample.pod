=head1 NAME

Sample - happy-path POD fixture for the gate's parser

=head1 SYNOPSIS

    my $s = Sample->new(size => 3);
    print $s->listed_params(1, 2);

=head1 DESCRIPTION

Documents Sample.pm. Every construct here exists to exercise one
parsing rule; failure cases live in their own fixtures.

=head1 METHODS

=head2 new

    my $s = Sample->new(%opts);

Builds a Sample.

B<Parameters:>

=over 4

=item C<%opts>

Arbitrary options, stashed on the object.

=back

B<Returns:> A blessed Sample.

B<Examples:>

    Sample->new(size => 3);
    # Returns: a Sample with size 3

=head2 listed_params($first, $second)

    my $sum = $s->listed_params($first, $second);

Adds two numbers.

B<Parameters:>

=over 4

=item C<$first>

The first addend.

=item C<$second>

The second addend.

=back

B<Returns:> The sum.

B<Examples:>

    $s->listed_params(1, 2);
    # Returns: 3

=head2 raises

    $s->raises($path);

Checks a path.

B<Parameters:>

=over 4

=item C<$path>

Path to check.

=back

B<Returns:> True.

B<Errors:> Dies with C<no such path> when the path does not exist.
Bails with C<cannot read> when it exists but cannot be read.

B<Examples:>

    $s->raises("/etc/hosts");
    # Returns: 1

    $s->raises("/no/such/file");
    # dies: no such path: /no/such/file

=head2 Notes on argument handling

This heading is prose, not a method. A parser that reads every
C<=head2> as a method name invents one called "Notes" and then
demands that Sample.pm define it.

=head3 A nested heading

Section attribution is by the nearest enclosing C<=head1>, not by the
last heading of any level. Treating C<=head3> as a boundary drops the
methods that follow it out of METHODS entirely.

=head2 mutates

Stores a value.

B<Parameters:>

=over 4

=item C<$v>

Value to stash.

=back

B<Returns:> The invocant.

B<Examples:>

    $s->mutates("cached value");
    # Returns: the same Sample, with {cached} set

=head2 shifted_params($only)

    my $v = $s->shifted_params($only);

B<Parameters:>

=over 4

=item C<$only>

The value to return.

=back

B<Returns:> C<$only>.

B<Examples:>

=head2 indexed_params

    my $v = $s->indexed_params($flag, $value);

Reads C<@_> by index rather than unpacking it.

B<Returns:> The third argument when the second is true, C<undef> otherwise.

=head2 context_sensitive

    my @all = $s->context_sensitive;
    my $n   = $s->context_sensitive;

Returns a list in list context and its length in scalar context.

B<Returns:> The list, or its count.

B<Examples:>

    my @all = $s->context_sensitive;
    # Returns: (1, 2, 3)

    my $n = $s->context_sensitive;
    # Returns: 3

=head2 to_string

    my $str = "$s";

Backs the C<""> overload.

B<Returns:> The string C<sample>.

=head2 equals

    my $same = ($a == $b);

Backs the C<==> overload.

B<Returns:> False, always.

=head2 optional_second($first, $second)

    my $s1 = $s->optional_second($first);
    my $s2 = $s->optional_second($first, $second);

Joins two strings; the second defaults when omitted.

Documented at both arities on purpose. Perl marks an optional parameter
with C<//=> or a C<defined> test rather than in the parameter list, so
the shorter call cannot be derived from the code -- and a check that
insists every documented call passes every parameter rejects the normal
way of showing an optional argument.

B<Parameters:>

=over 4

=item C<$first>

Required.

=item C<$second>

Optional; defaults to C<default>.

=back

B<Returns:> The two joined with a slash.

B<Examples:>

    $s->optional_second("a");
    # Returns: a/default

    $s->optional_second("a", "b");
    # Returns: a/b

=head1 INTERNAL METHODS

=head2 _private_helper

    $s->_private_helper;

Returns the answer.

B<Returns:> 42.

=head1 OPERATOR OVERLOADING

=head2 Stringification

Overloads C<""> to return the string C<sample>. Headed by the concept
rather than the operator, which reads better but is not a method name --
Sample.pm has no sub called Stringification and never will.
