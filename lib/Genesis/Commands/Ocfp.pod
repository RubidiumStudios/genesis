=head1 NAME

Genesis::Commands::Ocfp - Command dispatch for OCFP environment management

=head1 SYNOPSIS

  # Registered in bin/genesis via define_command:
  genesis <env> ocfp show network [options]

=head1 DESCRIPTION

Provides the top-level command dispatch for OCFP (Open Cloud Foundry Platform)
environment management and inspection commands.  The dispatch follows a
two-level topic/action pattern:

  ocfp <topic> <action>

Currently supported:

=over 4

=item C<show network>

Display network configuration, IP reservations, allocations, and
availability.  See L<Genesis::Commands::Ocfp::ShowNetwork> for details.

=back

=head1 FUNCTIONS

=head2 ocfp($env_name, $topic, $action, @extra_args)

Top-level entry point registered with C<define_command>.  Validates the
environment is OCFP-enabled, then dispatches to the appropriate topic handler.

B<Parameters:>

=over 4

=item C<$env_name> - Environment name string

=item C<$topic> - The topic (currently only C<show>)

=item C<$action> - The action within the topic (currently only C<network>)

=item C<@extra_args> - Any additional arguments (currently rejected)

=back

The topic and action are validated before the environment is loaded, so a
mistyped subcommand is answered immediately rather than after the cost of
loading an environment and unlocking its vault.

B<Returns:> Whatever the dispatched topic handler returns. Falls off the end
returning nothing if the topic passed validation but matched no branch --
unreachable while C<show> is the only topic, but worth knowing when a second
one is added.

B<Errors:>

=over 4

=item *

C<"Environment name, topic, and action are required"> -- raised via
L<Genesis::Commands/command_usage> when any of the three is missing.

=item *

C<"Too many arguments provided"> -- raised via C<bail()> when arguments
follow the action.

=item *

C<"Invalid topic: '%s' - expected one of: %s"> -- raised via C<bail()>. The
second C<%s> lists the valid topics, so the message names the alternatives
rather than only rejecting the input.

=item *

C<"Environment '%s' is not an OCFP environment.\nThe 'ocfp' command requires an environment with the 'ocfp' feature enabled."> --
raised via C<bail()> when the environment loads but lacks the feature.

=back

B<Examples:>

  # CLI: genesis my-env ocfp show network
  ocfp('my-env', 'show', 'network');
  # prints the network overview

  # CLI: genesis my-env ocfp list network
  ocfp('my-env', 'list', 'network');
  # bails: Invalid topic: 'list' - expected one of: show

  # A non-OCFP environment:
  ocfp('plain-env', 'show', 'network');
  # bails: Environment 'plain-env' is not an OCFP environment. ...

=head2 ocfp_show($env, $action, %options)

Dispatches C<show> topic actions.  Currently supports:

=over 4

=item C<network> - Delegates to L<Genesis::Commands::Ocfp::ShowNetwork/run>

=back

The implementing module is loaded on demand rather than at C<use> time, so
the cost is paid only by the command that needs it.

B<Parameters:>

=over 4

=item C<$env>

A C<Genesis::Env>, already loaded and vault-attached by C<ocfp>, and already
confirmed to be OCFP.

=item C<$action>

The action to run. Currently only C<network>.

=item C<%options>

Parsed command-line options, passed through to the action unchanged.

=back

B<Returns:> Whatever the action returns. As with C<ocfp>, returns nothing if
the action validated but matched no branch.

B<Errors:>

=over 4

=item *

C<"Invalid show action: '%s' - expected one of: %s"> -- raised via C<bail()>,
naming the valid actions.

=back

B<Examples:>

  ocfp_show($env, 'network', %options);
  # prints the network overview, via ShowNetwork::run

  ocfp_show($env, 'subnets', %options);
  # bails: Invalid show action: 'subnets' - expected one of: network

=head1 ENVIRONMENT REQUIREMENTS

The target environment must have the C<ocfp> feature enabled
(C<< $env->is_ocfp >> returns true).  Non-OCFP environments produce a clear
error message.

For create-env environments where the BOSH director exodus data is not
available, commands degrade gracefully by showing OCFP configuration data
without BOSH IP claims.
